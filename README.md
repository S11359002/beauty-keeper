# Beauty Keeper — 個人美妝保養品管理與消費輔助系統

依據 Beauty Keeper SRS 建立的可執行全端網站，介面使用繁體中文。

## 已實作

- 註冊／登入（JWT、bcrypt）與使用者資料隔離
- 品牌、分類與產品目錄建立
- 個人美妝庫存（同產品可有多件、獨立期限與狀態）
- 未開封期限／開封後 PAO 期限計算與 30 天內提醒
- 購物前庫存檢查、最新評價與回購意願
- 購買紀錄、自動建立庫存、月份消費統計與預算
- 願望清單與狀態更新
- 多筆歷史使用心得（不覆蓋舊紀錄）

## 執行環境

Node.js 20+、PostgreSQL 16+、npm。

### 1. 建立資料庫

```bash
createdb -U postgres beauty_keeper
psql -U postgres -d beauty_keeper -f db/schema.sql
```

若 `createdb` 不在 PATH，可用 pgAdmin 建立 `beauty_keeper` 資料庫，再開啟 Query Tool 執行 `db/schema.sql`。

### 2. 設定後端

複製 `server/.env.example` 成 `server/.env`，設定你的 PostgreSQL 帳號密碼及**強隨機 JWT_SECRET**。

### 3. 安裝並啟動

```bash
npm run install:all
npm run dev
```

瀏覽器開啟 **http://localhost:5173**，註冊帳號後即可使用。

## 操作順序

1. 在「我的美妝庫」點選「建立產品目錄」，先新增品牌／分類／產品。
2. 點選「新增庫存」補登現有產品，或到「消費管理」記錄購買（會自動建立庫存）。
3. 到「使用心得」記錄評分與回購意願，同款產品可記錄多次。
4. 在「購物前檢查」查詢已有數量、歷史心得與最新回購意願。

## 規格與目前限制

- 到期提醒為**站內清單**，不是手機推播；頁面載入時依資料即時計算。
- 系統架構採 React + Vite / Express / PostgreSQL；未部署到公開網址。
- 購買介面目前一次輸入一個品項；後端每次購買建立一筆主紀錄與一筆明細，資料表仍支援一筆訂單多品項的擴充。
- 產品目錄目前允許已登入使用者新增；SRS 中 ADMIN 專屬的目錄管理權限尚未完整實作。
- 尚未提供產品照片上傳、推播、管理員介面或自動化測試。
- 生產環境需要額外部署 HTTPS、流量限制、完整監控及安全性測試。

此版本定位為可實際操作的**本機全端初版**，非已完成部署或通過正式驗收的產品。
