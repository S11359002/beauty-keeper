# Beauty Keeper｜美麗有數

### 個人美妝保養品管理與消費輔助系統

Beauty Keeper（美麗有數）是一套結合**美妝保養品庫存管理、保存期限追蹤與消費決策輔助**的網頁系統。

本專案旨在解決使用者購買美妝保養品後，容易忘記現有庫存、產品保存期限及過往購買紀錄等問題。透過整合個人庫存、購買紀錄、使用心得與預算管理，協助使用者更有效率地管理美妝保養品，減少重複購買與浪費。

## 專案功能

### 1. 美妝保養品庫存管理
- 建立個人美妝保養品庫存。
- 記錄產品品牌、分類與名稱。
- 管理未開封、已開封、已用完及已丟棄等狀態。
- 支援同一產品的多筆獨立庫存紀錄。

### 2. 保存期限與開封管理
- 記錄產品有效期限與開封日期。
- 依據 PAO（Period After Opening）追蹤開封後使用期限。
- 提供即將到期的產品提醒，協助使用者優先使用現有產品。

### 3. 購買紀錄管理
- 記錄購買日期、產品、數量與價格。
- 查詢歷史購買紀錄。
- 整合購買資訊，方便追蹤美妝保養品消費情況。

### 4. 願望清單
- 收藏未來想購買的產品。
- 記錄預期購買價格。
- 管理考慮中、已購買與已取消的願望狀態。

### 5. 使用心得紀錄
- 記錄產品評分與使用心得。
- 保存回購意願。
- 作為未來購買相同產品時的參考。

### 6. 預算與消費輔助
- 設定每月美妝保養品預算。
- 統計購買支出。
- 結合現有庫存與購買紀錄，協助使用者做出更合理的消費決策。

### 7. 會員與管理員系統
- 支援會員註冊、登入及登出。
- 使用 JWT 進行身分驗證。
- 各會員的個人庫存、購買紀錄、心得及願望清單相互隔離。
- 提供管理員後台與基本管理功能。

## 專案特色

**個人化庫存管理**

同一款產品可以建立多筆獨立庫存，分別追蹤保存期限、開封日期與使用狀態。

**結合消費決策**

不只記錄擁有的產品，也整合購買紀錄、願望清單、使用心得與預算，協助使用者評估購買需求。

**會員資料隔離**

透過 JWT 身分驗證及後端資料存取權限控制，確保不同會員只能管理自己的個人資料。

**完整的全端開發架構**

整合 React 前端、Express 後端、PostgreSQL 關聯式資料庫與雲端部署，實作完整的網頁應用系統。

## 專案目標

希望透過 Beauty Keeper，讓美妝保養品管理不再只是單純的產品紀錄，而是能協助使用者掌握庫存、追蹤保存期限、回顧使用經驗，並建立更有規劃的消費習慣。
